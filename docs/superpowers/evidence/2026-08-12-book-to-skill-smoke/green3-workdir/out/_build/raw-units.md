# raw-units — улов фазы 1

Формат отличается от YAML-схемы листа `01-extractors.md`: единицы сведены в
таблицу, чтобы рабочий след на 170+ кандидатов остался обозримым. Обязательное
сохранено — у каждой единицы есть дословный якорь (греп-строка) и адрес раздела.
Полные поля (why / applies_when / authors_caveat / пример) развёрнуты уже в
листах собранного скилла.

Экстракторы прогонялись пятью последовательными проходами по срезам источника
(нарезка по заголовкам `##`): «Знакомство и уровни» (88–490), «Слово» (492–1930),
«Предложение» (1929–3360), «Канцелярит» (3356–3800), «Текст большими мазками»
(3830–4260), «Структуры» (4213–4900), «Введение, тональность» (4900–5310),
«Багаж и глубина» (5308–5620), «Жанры» (5621–7370), «На прощание» (7648–7790).
