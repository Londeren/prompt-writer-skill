# book-to-skill: ревью черновика и история решений

Дата: 2026-08-12. Основание плана [2026-08-12-book-to-skill-production.md](../plans/2026-08-12-book-to-skill-production.md). Здесь полный контекст, на который план ссылается: вердикт по черновику, таблица дефектов с номерами, история решений Сергея, разбор инсайтов смежной сессии. Документ существует, чтобы независимая проверка плана и его исполнитель не зависели от сессии, в которой ревью проводилось.

Черновик: `tmp/books to skill/`, пять файлов (SKILL.md и листы 01-extractors, 02-validation, 03-output-format, 04-evals), около 66 Кб, целиком на русском, frontmatter name `method-to-skill`. tmp/ в .gitignore: если файлов нет локально, запросить у Сергея.

Ревью велось против трех систем координат: мастер-правила prompt-writer (`plugins/prompt-writer/SKILL.md`), его self-check (`plugins/prompt-writer/checklists/self-check.md`) и скилл superpowers:writing-skills (TDD для скиллов, правила SDO для description).

## Вердикт

Черновик методологически крепкий, почти готовая архитектура. Ядро валидно: различие «справочник против скилла», якорь как механическая защита от выдумки, разделение ролей добытчик/валидатор, три фильтра, rejected.md как инструмент диагностики, фаза эвалов с блайнд-грейдером. Фаза 4 местами сильнее аналога из writing-skills: held-out split при настройке триггера, порог «baseline ниже 70 процентов, иначе скилл не нужен». До продакшена черновик отделяли внутренние противоречия, одно нарушение SDO и упаковка.

## Сильное, не потерять при правках

Сводный список: ревью этой сессии плюс оценка из смежной (`tmp/books-to-skill-insights.md`).

- Различение «справочник по книге против скилла с методом» первым абзацем, рамка всему.
- Тест каждой строки: пригодится ли агенту, который работает с материалом пользователя и книгу не читал.
- Правило «якорь появляется до формулировки, а не подбирается под нее».
- Фаза go/no-go с формулировкой «отказ это результат, а не провал» и примерами отказов.
- Валидацию выполняет агент, не участвовавший в добыче.
- Нормы отбраковки числами; rejected.md и его роль в разборе провалов эвалов («чаще срезали фильтром 3, чем не нашли»).
- Master rules продублированы рядом с местами применения, помечено как намеренное.
- Добытчик D (антипаттерны и границы) выделен как самый дорогой и первым исчезающий при суммаризации материал.
- Эвалы: состав набора долями, утверждения с вердиктом по цитате, блайнд-грейдер, пороги, настройка триггера с отложенной половиной.

## Решения Сергея и их история

Все решения приняты 2026-08-12 через явные вопросы с вариантами.

1. **Имя: `book-to-skill`.** Альтернативы: `method-to-skill` (точнее по сути, но никто не ищет через «метод»), `books2skill` (цифра в id хуже читается). Выбран поисковый термин пользователя.
2. **Язык: английский, в description смешанные EN+RU триггеры.** Альтернативы: оставить русский (режет аудиторию публичных каналов), RU-релиз с переводом потом (два релиза). Конвенция репозитория, прецедент prompt-writer.
3. **Якоря в готовом сгенерированном скилле, два раунда.** Первый раунд: «адрес без цитаты» (мотивы: копирайт при шеринге, вес листов). Пересмотрено в тот же день после разбора `tmp/books-to-skill-insights.md`: критерий приемки первого потребителя «метод без необходимости хранить источник рядом», оригиналы книг в репозиторий потребителя не заводятся, и юниты с цитатами внутри заменяют RAG-паттерн оригинального claude.ai-проекта («сначала фрагмент, потом рассуждение»). Итог: якорь (цитата 1-3 предложения плюс адрес) остается полем юнита в листах; в 03 заметка одной строкой о срезе цитат до адресов при публикации скилла наружу. Отклонена полноценная развилка-режим в фазе 3 как лишняя сложность пайплайна.
4. **Эталона для калибровки нет.** Смоук по логике writing-skills: RED baseline без скилла против GREEN со скиллом на реальном источнике из tmp/. Кандидат: книга Ильяхова из локального экспорта claude.ai (markdown через mineru).

Решения из смежной сессии (зафиксированы в `tmp/books-to-skill-insights.md`, файл локальный, суть повторена здесь): скилл переписывается по методологии prompt-writer; живет отдельно от потребителя gg-wiki (этот репозиторий и есть отдельный); первое применение - книги Ильяхова для цеха постов gg-wiki; дистиллят самодостаточен без источника; запасной вариант при нехватке плотности - обрезанные версии книг, не полные тексты. Последнее в план не заводится и зафиксировано в его разделе «Вне плана, сознательно»: это решение конкретной сборки, слот под него скилл не выделяет.

| Инсайт | Судьба | Место в плане |
|---|---|---|
