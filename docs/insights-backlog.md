# Backlog инсайтов

Отклоненные и отложенные инсайты по скиллу `prompt-writer`. Одна строка на инсайт.

Формат колонок:

- **Инсайт**: суть одной фразой.
- **Источник**: файл и строка или URL.
- **Статус**: `rejected` или `deferred`.
- **Причина**: решение Сергея своими словами, почему инсайт не вошел сейчас.

Строки попадают сюда только из прогонов протокола "Changing the skill" (CLAUDE.md), после таблицы доводов и решения Сергея. Напрямую, минуя протокол, сюда не пишут.
